# ERP Brasilino — Brasilino Produtos Metalúrgicos

Sistema ERP em um único arquivo HTML (`index.html`): orçamentos, propostas, obras, compras, estoque e financeiro.

## Publicar no GitHub Pages
1. No repositório: **Settings → Pages**.
2. Em **Source**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
3. Salve. O endereço aparece em alguns minutos.

## Aviso
Os dados ficam no navegador de cada computador. Não há sincronização entre aparelhos.
